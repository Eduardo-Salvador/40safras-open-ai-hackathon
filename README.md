# Quarenta Safras

Harness, product specification, architecture, task graph, and specialist-agent contracts
for the Quarenta Safras project.

Quarenta Safras is a voice, text, and form operational planting planner. A producer sees
which operation details are needed, chooses how to provide them in Portuguese, confirms
the shared structured draft, and asks it to calculate a
soybean-to-corn planting sequence for any Brazilian municipality. Deterministic code
stress-tests the sequence against 41 historical seasons and produces an auditable replan
when field conditions change. The result can be heard, read, and shared through WhatsApp.
